2026年8月第五周（8月18日～8月25日），GitHub AI 赛道呈现三大热点：AI Agent 上下文与记忆基础设施、AI 安全与红队工具、以及AI 视频创作自动化。火山引擎的 OpenViking 以一周 4,048 新星空降榜首，Apache 孵化器项目 Maka 和本地优先 Agent 框架 Waku Agent 紧随其后。安全赛道上，腾讯开源的 AI-Infra-Guard 红队平台和 Capital One 的 VulnHunter 成为新宠。视频创作方面，MoneyPrinterTurbo 持续霸榜，OpenChatCut 和 Vox-Director 两大新工具齐发。本周 AI 新增 Stars Top 10 如下。

三、趋势分析

1. Agent 上下文基础设施成为共识赛道

本周最显眼的是 OpenViking 和 Maka。前者将 Agent 记忆+RAG+技能整合为一个虚拟文件系统，后者用追加日志确保 Agent 行为完全可审计。两者殊途同归——Agent 的”大脑”需要被结构化、可追溯、可管理，正如人在工作中需要笔记和流程一样。Waku Agent 和 fastctx 进一步补充了 Agent 本地化和上下文效率的拼图。

2. AI 安全进入”红队标准化”阶段

本周安全相关项目数量和内容深度令人瞩目：腾讯 AI-Infra-Guard 覆盖 Agent/ Skills/MCP/LLM 全栈扫描；Anthropic 生态的 Cybersecurity-Skills 提供 817 个标准化安全技能；Capital One VulnHunter 和 Strix 的 Agentic 渗透测试定位攻防两端。AI 安全已从”意识觉醒”进入”工具落地”阶段。

3. AI 视频创作从”玩具”走向”生产力工具”

MoneyPrinterTurbo 连续多周霸榜已经证明了市场需求，本周 OpenChatCut（AI 对话视频编辑器）和 Vox-Director（一键 Vox 风格视频）分别从”对话转视频”和”主题转视频”两个方向切入。加上 Claude Design 生态中对可视化输出工具的持续投入，AI 视频正在从 GPT-4o 的能力演示进化为独立产品线。

4. 本地优先 + 隐私驱动

Maka、Waku Agent、munder-difflin、modlens、career-ops——本周多个 Top 项目明确打出”本地优先”旗号。当 AI Agent 深入企业场景后，数据不出本地不再是卖点，而是底线要求。这一趋势将推动更多 AI 工具向 edge computing 方向演进。

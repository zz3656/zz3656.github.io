### 3. Hermes Agent 技能系统与自我进化机制

从官方文档了解到 Hermes Agent 的核心架构，其差异化在于"运行时间越长，能力越强"：

**五大核心模块**：
1. **技能系统（Skills）**：类似 LangChain Tools，可扩展的工具集
2. **长期记忆（Memory）**：跨会话存储信息，使 Agent 能"记住"之前的交互，这是"自我进化"的基础
3. **MCP（Message Passing/Control）**：消息传递/控制协议，用于模块间通信
4. **消息网关（Message Gateway）**：支持 Telegram 等多平台接入
5. **自动化工作流（Automation）**：预设任务模板，定时/触发执行

**"运行时间越长，能力越强"的原理**：传统 AI 助手每次对话是独立上下文，而 Hermes Agent 通过 Memory 模块把历史交互沉淀下来——偏好、已解决的问题、常用工具链，形成越来越精准的"个人模型"，类似于人类专家的经验积累。

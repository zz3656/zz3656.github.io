## 内容详解

### 要点一：MCP 与 Hermes 的过滤机制

MCP 服务器连接到 Hermes Agent 后，可通过白名单或黑名单过滤其工具，保障安全。实际影响的是工具的实用封装器（utility wrapper），而非底层 MCP 工具本身。支持同时配置白名单和黑名单，例如白名单允许特定操作、黑名单屏蔽危险操作。这套机制让用户在引入第三方 MCP 工具时既有灵活性又有安全保障。

### 要点二：Cron 定时任务的生命周期管理

Hermes Cron 支持创建、暂停、恢复、编辑、触发和删除任务。关键限制：Cron 执行的会话无法递归创建更多 Cron 任务（防止无限循环）。任务可通过斜杠命令或独立 CLI 管理，支持为零个、一个或多个技能附加，支持交付到聊天会话、本地文件或配置的平台目标。

### 要点三：三大自动化触发类型

Hermes 自动化基于三种触发器：计划任务（按节奏运行）、GitHub 事件（PR/推送/CI 触发）、API 调用（外部服务 POST JSON）。所有类型均支持交付到 Telegram、Discord、Slack、邮件、GitHub 评论或本地文件。三种触发器配合 Cron 调度器和 Webhook 平台工作，构成了完整的事件驱动自动化体系。

### 要点四：记忆提供者多元化

Hermes 支持多种外部记忆提供者插件：Honcho、OpenViking、Mem0、Hindsight、Holographic、RetainDB、ByteRover、Supermemory。这为自托管部署提供了灵活的长期记忆方案，可根据需求选择不同提供者的特性，实现跨会话的持久化记忆存储。
